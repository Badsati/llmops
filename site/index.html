System Design

Platform Architecture

Five components, one stack. Data flows from client requests through the API gateway, into the LLM and vector store, with every request captured by the observability layer.

Workflows

How It Works

Three distinct interaction patterns, each building on the same infrastructure.

1

Client sends a prompt

An HTTP POST to /api/v1/inference with the question, optional system prompt, temperature, and token limit.

FastAPI
2

Gateway validates & routes

FastAPI validates the request schema, records a Prometheus counter, and starts a latency timer.

FastAPI · Prometheus
3

Ollama generates a response

The prompt is forwarded to Ollama's /api/generate endpoint. Qwen 2.5 3B runs on CPU (or GPU if available) and streams tokens until complete.

Ollama · Qwen 2.5 3B
4

Metrics recorded & response returned

Token count, duration, and tokens-per-second are captured. The JSON response is returned to the client with full attribution.

~4–15 s on CPU
1

Upload a PDF document

A PDF is submitted via POST /api/v1/documents as a multipart upload. Only PDF format is accepted.

FastAPI
2

Text extraction & chunking

PyPDF extracts text page-by-page. RecursiveCharacterTextSplitter breaks the content into 1,000-token chunks with 200-token overlap to preserve context.

LangChain · PyPDF
3

Embed & store

Each chunk is passed to Ollama's nomic-embed-text embedding model, producing a 768-dimensional vector. Vectors and metadata (filename, page) are persisted in ChromaDB.

Ollama Embeddings · ChromaDB
4

Query with semantic search

A question at POST /api/v1/rag/query is embedded and compared against all stored vectors. The top-4 most semantically similar chunks are retrieved.

ChromaDB · cosine similarity
5

Grounded answer with citations

Retrieved chunks are injected into a strict system prompt that tells the LLM to answer only from the provided context. The response includes source filename and page numbers.

Ollama · Qwen 2.5 3B
1

Query arrives at the agent

A question is sent to POST /api/v1/agent/query. The agent can handle multi-step questions that need both document lookup and calculation.

FastAPI · LangGraph
2

LangGraph ReAct loop starts

Qwen 2.5 3B receives the query and a list of available tools. It decides which tool to call first based on the question.

LangGraph · Qwen 2.5 3B
3

Tool: Search Documents

If the question requires knowledge from uploaded documents, the agent calls search_documents which performs a ChromaDB semantic search and returns the top matching excerpts.

ChromaDB · nomic-embed-text
4

Tool: Calculator

For numerical questions, the agent calls calculate — a sandboxed AST evaluator that safely handles arithmetic expressions (+, −, ×, ÷, ^) with no code execution risk.

Safe AST Evaluator
5

Final answer synthesised

After all tool calls complete, the LLM synthesises a final answer combining document evidence and computed results. The response lists all tools used and the number of reasoning steps.

LangGraph · Qwen 2.5 3B

Technology

Stack Overview

Every component is open-source, runs locally, and requires no paid API keys or cloud dependencies.

🤖
Ollama
LLM Inference Server
Runs open-source language models locally. Provides a REST API compatible with OpenAI's format. Handles both text generation and embedding workloads.
🧠
Qwen 2.5 3B
Language Model
3-billion parameter model from Alibaba. Runs on CPU with 4–6 GB RAM. Supports tool calling, instruction following, and multi-language output.
⚡
FastAPI
API Gateway
High-performance async Python framework. Handles request validation, error handling, Prometheus metric collection, and health checks.
🔗
LangChain + LangGraph
RAG Orchestration + Agents
LangChain orchestrates the full RAG pipeline — text splitting, embedding, retrieval. LangGraph powers the ReAct agent loop with tool calling.
🗄
ChromaDB
Vector Database
Persistent vector store for document embeddings. Runs as a standalone service with HTTP API. Supports cosine similarity search over millions of vectors.
📊
Prometheus + Grafana
Observability
Prometheus scrapes 8 custom metrics every 15 s. Grafana dashboard auto-provisions on startup — inference volume, latency, error rate, and token throughput.
🐳
Docker Compose
Local Deployment
Single docker compose up -d starts all five services. Persistent volumes, health checks, and environment-based configuration included.
☸️
Kubernetes
Container Orchestration
Full manifest set for Namespace, ConfigMap, Secrets, PVCs, Deployments, and Services. Works on Minikube, k3d, GKE, EKS, and AKS.
⛵
Helm
Kubernetes Packaging
Parameterised Helm chart with values for model selection, resource limits, and optional NVIDIA GPU scheduling. Passes helm lint clean.

API Reference

Key Endpoints

All endpoints are served from the FastAPI gateway at :8000. Full OpenAPI docs available at /docs.

GET /health Service health + Ollama status 
// Response
{
  "status": "healthy",
  "ollama": "up",
  "version": "1.0.0"
}
POST /api/v1/inference Direct LLM generation 
// Request
{
  "prompt": "Summarise the key risks in the attached report.",
  "model": "qwen2.5:3b",
  "temperature": 0.7,
  "max_tokens": 1024
}

// Response
{
  "text": "The report identifies three primary risks...",
  "tokens_generated": 142,
  "duration_seconds": 9.4,
  "tokens_per_second": 15.1
}
POST /api/v1/documents Upload & index a PDF 
// multipart/form-data  →  file: annual_report.pdf

// Response
{
  "message": "Document indexed successfully",
  "filename": "annual_report.pdf",
  "pages": 48,
  "chunks": 187
}
POST /api/v1/rag/query Document-grounded Q&A 
// Request
{
  "question": "What were the key findings in Q3?",
  "top_k": 4
}

// Response
{
  "answer": "According to [annual_report.pdf, p.12], Q3 saw...",
  "sources": [{ "filename": "annual_report.pdf", "page": 12 }],
  "context_used": true,
  "chunks_retrieved": 4
}
POST /api/v1/agent/query Multi-step AI agent 
// Request
{ "query": "What is the budget projection? Also calculate 1.08 * 2500000." }

// Response
{
  "answer": "The report projects $2.5M. At 8% growth: $2,700,000.",
  "tools_used": ["search_documents", "calculate"],
  "steps": 5
}
